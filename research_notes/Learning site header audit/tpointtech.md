## How does a tutorial page show the chapter list, the current page, and the next chapter?

### Takeaway
On a wide screen the chapter list is a left sidebar of every Python page, grouped but all expanded, and the current page is not marked in that list. The next chapter is named at the bottom of the article. On a phone the sidebar is hidden until a hamburger opens it as a fixed overlay.

### Cited Findings
- Chapter audited: [What is Python](https://www.tpointtech.com/what-is-python), final URL the same, title "What is Python - Tpoint Tech". It is linked as the next page from [the Python tutorial hub](https://www.tpointtech.com/python-tutorial) (`href=what-is-python` on both the top `#bottomnextup` control and the end-of-page Next Topic). The hub’s visible sibling links, from `custom-nav-node` spans, are Compiler, Programs, Lists, Tuples, and Interview Questions (`/compiler/python`, `python-programs`, `python-lists`, `python-tuples`, `python-interview-questions`). The chapter page itself has no `custom-nav-node` row. — [python-tutorial](https://www.tpointtech.com/python-tutorial); [what-is-python](https://www.tpointtech.com/what-is-python)
- Desktop (1440px screenshot): under the same two bars, a left column lists accordion headings and links. First heading "Python Tutorial" is expanded and shows Python Tutorial, What is Python, Python Features, Advantages of Python, History of Python, and more. Further headings visible without scrolling the page include Python Variable & Data Type, Python Control Statements, and Python Data Structures, also expanded (chevron points up). "What is Python" is the same weight and color as its siblings. — chapter screenshot 1440×1400
- The sidebar is `div.col-md-2.sidebar` > `#menu-sidebar`. HTML contains 23 accordion headings and 271 `li.leftmenu` links. Counts by heading: Python Tutorial 13, Python Variable & Data Type 7, Python Control Statements 10, Python Data Structures 13, Python Functions 4, Python Modules 8, Python OOPs 8, Python Exception Handling 5, Python File Handling 7, Python Searching & Sorting 11, Python Advanced Topics 26, Python MySQL 9, Python MongoDB 1, Python SQLite 1, Python MCQ 2, Python Tkinter (GUI) 20, Python Web Blocker 4, Python Built-in Functions 60, Python String functions 41, Python List 8, Python Dictionary 6, Plotly 2, Related Tutorials 5. — [what-is-python HTML](https://www.tpointtech.com/what-is-python)
- `handleAccordionOnLoad` adds `.show` to every `.accordion-collapse` when `window.innerWidth > 768`, so desktop opens every group. At `<= 768` it removes `.show` from all groups, then reopens a group only if a link’s `getAttribute("href")` equals `location.pathname`. The links are absolute (`https://www.tpointtech.com/what-is-python`); the pathname is `/what-is-python`. CSS would highlight `div#menu-sidebar ul a.active` in green, but the chapter HTML has no `active` class on these links and no script that adds one. — [what-is-python HTML](https://www.tpointtech.com/what-is-python); [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- Sidebar width in CSS: 16rem when `max-width: 1485px`, 18rem when `min-width: 1500px`. At `max-width: 995px`, `.col-md-2.sidebar { display: none }`. `#menu-sidebar { height: 100vh }` and the column scrolls vertically with the scrollbar hidden. Link text is 14px under 1485px, with `width: 150%`. — [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- `toggleSidebar`, called on load and from the green bar’s hamburger, runs only when `innerWidth <= 895`. It reads the inline `style.display` (empty on first load, so not `"none"`) and therefore sets the sidebar and `.leftmenu` to `display: none`. The next tap sets `display: block`, `position: fixed`, and `z-index: 555`. So the phone chapter list is a fixed overlay, not a column beside the lesson. — [what-is-python HTML](https://www.tpointtech.com/what-is-python)
- Current page in the article header is a breadcrumb, not a sidebar state: Home (home icon) › Python (`/python-tutorial`) › What is Python (a `span.title-text`, not a link). A small script removes the title crumb when the page is the tutorial hub itself. The 1440, 390, and 320 chapter screenshots all show this crumb. Under the H1, gray text says "Last Updated : 13 Apr 2026". — [what-is-python HTML](https://www.tpointtech.com/what-is-python); screenshots
- Next and previous exist twice in the HTML. Top: `#bottomnextup` with `next →` to `python-features` and `← prev` to `python-tutorial`. CSS is `div#bottomnextup { display: none }`, and neither 1440 nor 390/320 screenshots show those buttons above the title. Bottom: `#bottomnext` repeats the same two links (`padding: 4px 20px` on `div#bottomnext a`). Above that, visible in the fetched article, is "Next Topic" linking to Python Features (`span.nexttopictext` / `span.nexttopiclink`). There is no "lesson N of M". — [what-is-python](https://www.tpointtech.com/what-is-python); [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- The Python hub page (not the chapter) is where Compiler / Programs / Lists / Tuples / Interview Questions sit, so the hub separates the written tutorial from interview questions and from the compiler. The chapter sidebar still includes a "Python MCQ" group (2 links) and "Related Tutorials" (5 links) inside the same list as the lessons. — [python-tutorial](https://www.tpointtech.com/python-tutorial); chapter HTML

### Inferences
- "You are here" on a desktop lesson is the breadcrumb plus the H1. The sidebar does not carry it. A reader looking at the list cannot see the current row.
- The phone script that was supposed to open only the current group cannot match, so a closed list is 23 headings with the current page buried. Combined with the fixed overlay, the chapter list is a poor phone control even though the groupings themselves are sensible.
- Hiding the top prev/next and naming the next page only at the bottom means the chrome does not answer "what is next?" until the chapter is finished. That is the opposite of Chaduvuko’s header, which already shows Previous, Next, and lesson N of M.

### Gaps
- The opened phone overlay was not screenshotted. Fixed positioning, z-index 555, and `display` toggling are from the script and CSS only.
- The bottom "Next Topic" row was in the fetched HTML and was not in the 1440×1400 viewport, which ends around the "Python Syntax" heading. Its on-screen size was not measured.

## How does search work, and is there any progress or "you are here" without an account?

### Takeaway
Search is a public box with no account: typeahead after two characters, Enter opens a result modal. It does not track progress. The only "you are here" is the breadcrumb. The live `/search` URL currently redirects to the homepage.

### Cited Findings
- Homepage search is the hero field `#searchInput`, placeholder "Search...", inside `#search-box` (CSS height 48.5px). The 1440, 390, and 320 homepage screenshots show that field in the hero, not in the white header. Tutorial pages move a "Search..." field into the top bar: centered on the 1440 chapter screenshot, and beside the logo on the 390 and 320 chapter screenshots. — [homepage HTML](https://www.tpointtech.com/); [chapter HTML](https://www.tpointtech.com/what-is-python); screenshots
- The inline script `performSearch` runs on input. If the query is shorter than 2 characters it clears `#results`. Otherwise it `$.get('/search', { q: query })` and fills a dropdown (`#results`: absolute, under the field, max-height 300px, each `li` padded 10px). Enter calls `performSearch(query, true)`, hides the dropdown, and opens Bootstrap modal `#searchModal`. The modal pages 10 results at a time, slices the list to 100, and prints "Showing X–Y of Z results". Each row is the title plus a generated sentence: "{title} with examples. Let's start learning {title} in detail on our website tpointtech.com". — [homepage HTML](https://www.tpointtech.com/)
- A direct request on 2026-10-09 to `https://www.tpointtech.com/search?q=python` with `X-Requested-With: XMLHttpRequest` and `Accept: application/json` returned HTTP 301 `Location: /`. Following redirects without that header returned the homepage HTML (about 312KB), not a JSON list. — request made 2026-10-09 to [the search URL](https://www.tpointtech.com/search?q=python)
- Both the homepage and the chapter also load Google Custom Search: `https://cse.google.com/cse.js?cx=548338c60d2224ac4`. CSS references `#___gcse_0`. The visible box is the custom `#searchInput`, not a CSE form, in the screenshots. — [chapter HTML](https://www.tpointtech.com/what-is-python); [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- No login, sign-in, register, account, or enroll control is in the chapter HTML (those strings are absent). Nothing in the chapter HTML records a completed lesson. `localStorage` appears for `popupShown` only in the popup timer. Theme colors are applied by inline `onclick` handlers; a stored progress object was not found. — [chapter HTML](https://www.tpointtech.com/what-is-python)
- "You are here" without an account is the breadcrumb Home › Python › What is Python, the H1, and the URL. The sidebar does not mark the row. There is no percent complete, no checkmark, and no "lesson N of M". — [what-is-python](https://www.tpointtech.com/what-is-python); 1440px sidebar crop

### Inferences
- Search is anonymous and global, which fits a no-account site, but the result line is a template sentence, not a track or a lesson number. A Chaduvuko search that already knows track, module, and lesson N of M would be more useful than this modal.
- Because `/search` 301s to `/`, the typeahead may be broken in the browser as well. That was not confirmed by typing into the field. The UI still shows the intent: a header or hero field, a short suggestion list, then a paged list.
- Tpoint’s account-free location is a breadcrumb because the chapter list fails to highlight the current page. Chaduvuko already puts track, module, title, and N of M in the one header, which is a stronger version of the same idea.

### Gaps
- The search field was not typed into, so suggestion rendering, empty states, and whether jQuery follows the 301 were not observed.
- Google CSE may power a box that was not in the first viewport. Its relationship to `#searchInput` was not executed.
- Theme persistence (localStorage versus cookies) was not fully traced past the inline `onclick` handlers.

## What is worth stealing for a written curriculum, and what is clutter?

### Takeaway
Steal three naming patterns: interviews kept out of the tutorial menu, a next chapter that says its title, and a one-line location that does not need an account. Refuse the second green bar, the 271-link phone overlay, and the ad slots that cover the lesson.

### Cited Findings
- Interviews and MCQs are a different mega-menu from Tutorials, and the Python hub adds a further split (Compiler, Programs, Lists, Tuples, Interview Questions) instead of dumping those into the top bar. The chapter sidebar then undoes some of that by putting "Python MCQ" and "Related Tutorials" in the same 271-link list. — [homepage HTML](https://www.tpointtech.com/); [python-tutorial](https://www.tpointtech.com/python-tutorial); [what-is-python](https://www.tpointtech.com/what-is-python)
- The end of the chapter names the following page: "Next Topic" plus "Python Features", with `← prev` back to the hub and `next →` to `python-features`. The duplicate pair above the H1 is hidden with `div#bottomnextup { display: none }`. — [what-is-python](https://www.tpointtech.com/what-is-python); [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- The breadcrumb is the only reliable location, and it works with no account: Home › Python › What is Python. It is on screen at 1440, 390, and 320. — screenshots of [what-is-python](https://www.tpointtech.com/what-is-python)
- The green `#link` bar is a second sticky strip (height 46px, sticky `top: 0`) of 20 to 22 short names, with a hidden scrollbar, clipped Aptitude and Reasoning on the homepage at 1440, and labels cut off at 390 and 320. — [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1); screenshots
- The chapter sidebar is 271 links, all open above 768px, and on a phone it is a `position: fixed` overlay at z-index 555 opened by the green hamburger. The current link is not highlighted, and the auto-open check compares an absolute href to the pathname. — [what-is-python HTML](https://www.tpointtech.com/what-is-python); [style.css](https://www.tpointtech.com/static/css/style.css?v=1.1)
- Ads are in the lesson template: empty `ad-container`, three `sidebar_300x600_*` slots, a ZoneId box covering paragraph text at 390px, and a chevron panel over "Python Syntax" at 1440px. Theme dots are 25px circles in the header. None of this helps a written lesson. — [chapter HTML](https://www.tpointtech.com/what-is-python); screenshots

### Inferences
- Chaduvuko should take these three Tpoint Tech elements, and nothing that adds a second bar:
  1. Take the **Interviews mega-menu** (including its **MCQs** group) as the pattern for keeping interview questions and practice banks out of the chapter list. The written tutorial stays a curriculum. Chaduvuko’s Practice and Interview items already match this split; the thing to copy is the discipline, not a third header menu.
  2. Take the end-of-page **Next Topic** label that names the next chapter ("Next Topic" / "Python Features"), not only an arrow. Chaduvuko’s header Next can show the next title in the same 64px bar. Do not also add Tpoint’s hidden top pair (`#bottomnextup`).
  3. Take the **breadcrumb** (Home › Python › What is Python) as the account-free "you are here" that still works when the chapter list is closed. Chaduvuko already has track, module, title, and lesson N of M in the one header; that single line is the right place for it. Do not add a second crumb row under the bar.
- Chaduvuko should refuse these three Tpoint Tech elements:
  1. Refuse the green **`#link` / `.ddsmoothmenu` shortcut bar** (Python through OS, plus Aptitude and Reasoning on the homepage). It is a second bar, it overflows at 320–390, and it steals the only phone row that should be the current track and Next.
  2. Refuse the **`col-md-2` chapter sidebar** in its real form: 271 links, every accordion open on a desktop, and `toggleSidebar` turning it into a fixed overlay (z-index 555) on a phone, with no current-page mark. Group headings are fine inside a menu Chaduvuko already has. A long list of every page on screen is not.
  3. Refuse the lesson **advertisement column** (`ad-container` and the three `sidebar_300x600_*` slots) and the ad box that covered the paragraph at 390px. Also refuse the header **theme-icon** dots and moon as chrome that does not help someone finish a lesson. Do not add a subscribe block, a popup, or any bar that hides on scroll. Tpoint does not use a phone bottom tab bar; do not invent one from this site.

### Gaps
- No second tutorial family (SQL or a data topic) was opened, so it is unproven that every subject uses this same 23-group sidebar. The header, the green bar, `#bottomnext`, and the ad slots are shared template pieces on the Python chapter and are likely site-wide, but that was not checked on a second subject.
- Open mega-menus, a typed search, a scrolled header, and the opened phone sidebar were not captured as screenshots.
