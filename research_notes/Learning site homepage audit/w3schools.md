# W3Schools homepage below the bar (2026-10-09)

Live audit of the page under the two fixed bars on https://www.w3schools.com/. Anonymous headless Chrome, CSS viewports 1440×900, 390×844, and 320×700. Body class after load: `w3s-user-anonymous`. The bars themselves are out of scope; they are only here as the 89px that sits on top of this page (`#pagetop` 56px, `#subtopnav` 33px). See the header audit for the bar. Shots from this run: `research_notes/Learning site homepage audit/w3schools-shots/`.

The hero is not in the static HTML. `#dashboard-hero` is filled by `DashboardLite.renderHero` from `/lib/account/dashboard-lite.js?updated=20260902`. A consent dialog did not cover these loads. No homepage leaderboard was in the HTML or in the fixed-element list. `sparteo.css` is linked; it did not paint a unit on these screens.
