# GeeksforGeeks homepage below the bar

Observed 2026-10-09, logged out, from `https://www.geeksforgeeks.org/` (HTTP 200, Next.js, build `2026-10-09T05-20-51-701Z`). The server payload had `countryCode` empty and, for a desktop user agent, `isMobileView: false`. CloudFront answered from LAX54-P9. Headless Chrome then measured the hydrated page at 1440×1000, 390×844, and 320×700 (desktop user agent, device scale 1), plus one 390×844 pass with an iPhone user agent. Shots: `research_notes/Learning site homepage audit/gfg-shots/1440-viewport.png`, `1440-full.png`, `390-viewport.png`, `390-full.png`, `320-viewport.png`, `320-full.png`. This note is the page under the bar. It does not re-audit the header.

The response is not a signed-in or India homepage. The homepage bundle renders a different block when `countryCode === "IN"`, and a consent modal when the country is in a 27-code EU list. Neither ran in this session. Chip records in the payload are dated 2026-08-25, not per-visitor.

### Inferences
- The page sells a catalog of portals. “Explore” sounds like reading and is fourteen doors, twelve of them topic indexes, one a practice advertisement, one an interview index. “Courses” is a paid shelf with ratings and crowd counts. “Must Explore” is not a curriculum: two of its four cards are “Watch Videos” and “Advertise with Us”, and advertising is already a full band above Courses.
- A reader cannot learn the difference between a tutorial, a course, a job, and practice from the body. Practice and jobs are footer words. The body uses “Explore” twice, once for topics and once in the footer, and “View more” / “Explore now” / “View All” for three different destinations.
- Putting the written grid above the paid grid is the only structural courtesy. It is undone by the hero, which asks for a course before the grid, and by the advertising band, which sits in the middle of the two.

### Gaps
- No India IP was loaded, so the GATE image and the India reorder were not seen painted. The JSX is the evidence.
- “LIVE COURSE” is painted on the course image in the 1440 and 390 screenshots. It is not a text node in the measured card string, so a screen reader gets the course title, level, count, and “Explore now”, not those badge words.
- The homepage stylesheet still defines a hero search input (779px wide, 66px tall; 90% width under 1100px). The hydrated DOM had zero `input` or `textarea` elements. Whether that field is behind a flag that another request turns on was not tested. — [Homepage CSS](https://assets.geeksforgeeks.org/gfg-assets/_next/static/css/27f3cb5d8310652f.css)
