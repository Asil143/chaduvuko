## 2. Core vision

Build a practical, globally accessible learning platform that takes learners from fundamentals to production-grade skills through:
- Structured roadmaps
- Short, progressive lessons
- Hands-on demonstrations
- Real-world projects
- Assessments and practice
- Career/interview preparation
- English-first instruction with multilingual subtitles where useful

The platform should avoid random topic ordering and should not jump into advanced material before prerequisites are taught.

## 3. Learning architecture

Reference source: roadmap.sh-style dependency thinking, adapted into a teachable Chaduvuko curriculum.

**Standard hierarchy:**

Domain → Track → Level → Module → Lesson → Practice → Project → Assessment → Next Level

### Standard levels
0. Prerequisites
1. Foundations
2. Core Skills
3. Advanced / Production
4. Real-World Engineering Projects
5. Career / Interview Preparation

### Lesson design rules
- One video = one clear learning objective.
- Concept lesson target: ~8–15 minutes.
- Hands-on demo target: ~15–25 minutes.
- Project lesson target: ~15–30 minutes.
- Split long lessons into logical parts rather than publishing unnecessarily long videos.
- The dependency graph determines lesson count; do not force every track to have the same number of videos.
- Approve the full curriculum before recording starts.

## 6. Careers & instructor hiring

The instructor is not just a classroom teacher. The role combines:
- Subject-matter expertise
- Curriculum design
- Technical instruction
- Educational content creation
- Hands-on demonstrations
- Projects, assignments and assessments
- Collaboration with technical reviewers/editors

### Preferred hiring model
For early-stage Chaduvuko:
- One strong lead instructor per track
- Paid pilot lesson/module before a larger commitment
- Course or milestone-based contract preferred initially
- Part-time technical reviewer where quality risk is high
- Move proven instructors to retainer/full-time only after recurring workload is stable
- Use specialist guest instructors for narrow advanced topics when needed

### Standard hiring flow
Application → Candidate Privacy Consent → Resume/Portfolio Screening → Teaching Demo → Technical Assessment/Interview → Paid Pilot → Quality Review → Selection → Written Contract/Offer → Verification → Onboarding → Course Production → Technical QA → Publishing → Performance Review

### Standard instructor performance criteria
- Technical accuracy
- Teaching clarity
- Curriculum completeness
- Code/project quality
- Practical usefulness
- Reliability and milestone delivery
- Responsiveness to review feedback
- YouTube views should not be the sole performance metric
